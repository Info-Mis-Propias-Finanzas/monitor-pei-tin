# Monitor PEI y TIN

Herramienta de Real Estate by MPF con el precio de cierre, el descuento frente al valor patrimonial, las distribuciones, el portafolio y la deuda de PEI y TIN, los fondos inmobiliarios listados en la Bolsa de Valores de Colombia.

Los precios se actualizan cada día hábil desde la BVC (`.github/workflows/actualizar-precios.yml`). Los demás datos de `data/` se actualizan cada trimestre. Detalles en `LEEME.md`.

Información educativa con datos públicos. No constituye asesoría ni recomendación de inversión.
